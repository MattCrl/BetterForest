# BetterForest 🌱

Minuteur de concentration : fais pousser des arbres pendant que tu te concentres.
Application web installable (PWA), données stockées uniquement sur l'appareil.

- Minuteur, chrono et cycles Pomodoro
- 16 espèces d'arbres, 3 stades de croissance (un toutes les 25 min)
- Forêt isométrique par jour / semaine / mois / année
- Statistiques, objectif quotidien, succès, favoris

Lancer en local : `node server.js` puis http://localhost:8765
